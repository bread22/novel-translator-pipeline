# Glossary grounding 分支评审与选择性合入

源分支：`origin/feat/glossary-grounding-calibration`，提交 `0935bbb`。基线：`7beb890`。

## 采纳

1. 移除生命周期激活中的额外 `confidence >= 0.92` 门槛。分数未经校准，不应使已通过名称、分类、正文证据校验且具独立复现证据的候选永久停留。该变更不删除名称验证、冲突处理或独立证据要求。
2. 章节最终知识决策同时纳入权威 glossary 中的 candidate 条目，避免只读取 knowledge-candidates 文件而漏掉另一处待激活候选。
3. 决策前使用实际正文补齐原文出现的段落与章节来源。出现次数仅是复现依据，不是译名正确性或多个模型达成共识的证据。映射仍经过 finalizer 和既有写入校验。

## 修正后采纳，未原样合并

- 扫描范围按 manifest 的章节顺序截止当前章，不扫描尚未到达的后文；章节 ID 不按字典序判断。
- 结构化段落只读取 source/text/original，不对整个 dict 做字符串匹配；保留段落/章节的正文与元数据范围，排除封面等来源。
- 使用显式章节字段；兼容既有标准段落 ID，不把任意自定义 ID 错当章节 ID。
- 保留 confidence=0，避免 `value or 1.0` 把低置信度改成满分。
- 拉丁名字边界匹配，Ann 不从 Anna/JoAnn 获得复现证据；不宣称实现了语义别名识别。
- 重新校验候选原有引用，移除无关引用且保留明确的丢弃原因；限制新增证据，重复调用保持幂等。
- 只在决策前扫描一次，不在 apply 阶段再次改变已经作出决策的证据集合。
- 修正 `_evidence_stats` 对 reporter 的计数：同一章节同一段落即使来自多个报告者也只算一次独立正文证据。

## 回归验证重点

新增贯穿测试：没有新的模型提取候选时，已有 0.88 置信度的人名在下一章出现后仍能被重新考虑，经 finalizer 确认后写入 active glossary、翻译投影，并被 select_relevant_terms 实际选中；第一章不会提前使用第二章的出现记录。

其它反例包括：元数据/仅译文出现、非标准段落 ID、零置信度、英文短名误匹配、无效旧引用、重复扫描、多个报告者重复计数。五项新增回归在源分支均失败，在选择性合入版本通过。

测试在隔离源码副本、示例配置下运行，不读取运行中服务的队列和真实模型配置。真实模型质量收益未作测量；不重启当前服务，也不自动修改已有书籍产物。完整命令、输出和回滚验证另存本地 `.codex-artifacts/glossary-calibration-20260908/`。
