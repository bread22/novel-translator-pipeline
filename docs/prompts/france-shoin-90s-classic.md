## 1. 核心词汇体系与官能描摹（90年代经典文库风骨）

- **生动地道的生理与器官用词**：
  - 核心部位统一使用经典文库译名：`肉棒`、`龟头`、`乳房`、`乳头`、`下体`、`阴唇`、`阴核`、`阴道`、`蜜穴`、`子宫`、`下腹`、`大腿根`。
  - 严禁现代网络低俗脏话化，亦不可过度文言晦涩化，保持 90 年代老译本特有的“露骨而通畅”的文风。
- **快感、体液与肉体反应**：
  - 高频使用老译本经典动词与形容词：`湿润`、`濡湿`、`充血`、`颤抖`、`抽搐`、`抽插`、`痉挛`、`瘫软`、`骚痒感`、`头昏目眩的高潮`、`甜美的快感`。
  - 将日文拟态拟声词（如 ズブッ、ビクンッ、ピクピク、キュン 等）转化为紧凑的动作描写（如“猛地插入深处”、“娇躯阵阵痉挛抽搐”、“从身体深处泛起难以忍受的快感”）。

## 2. 句式节奏与叙事韵律（短句连贯，拒绝冗长欧化长句）

- **动作与心理连贯推进**：
  - 遵循 90 年代港台文库本经典的短句结构，多用逗号拆分，动作与感官描写一气呵成。
  - *范例句式*：“受到微妙手法的玩弄，快要忍不住了，从身体内部产生甜美的快感，双手抓住皮沙发，不停扭动软绵绵的身体。”
- **鲜活传神的对话口吻**：
  - 人物对白保留日式文库本那股独特的张力与神韵，口语自然利落（如「你有什么事？是脚痛吗？」、「是……总算习惯了……」、「原来是你来了，年轻的也好」）。
  - 准确传达反派的轻佻猥亵、女主从抗拒/羞耻到沉沦的心理转变。

## 2.1 动态语境称谓与亲属关系原则（严禁机械死板硬套）

- **「先生（せんせい）」**：必须根据当前小说场景与人物职业精准翻译：
  - 学校/课堂场景：译为 **「老师」**（如西城先生 -> 西城老师）；
  - 医院/诊所场景：译为 **「医生 / 大夫 / 院医」**（如院長先生 -> 院长/医生）；
  - 法律/政商场景：译为 **「律师 / 议员 / 先生」**；
- **日语亲属称谓必须转换为自然的简体中文亲属称谓，不得保留日语构词形式**：
  - `兄嫁（あによめ）` 指哥哥的妻子；根据叙述视角和人物口吻译为 **「嫂子 / 兄嫂 / 大嫂」**，不得在中文正文或标题中保留「兄嫁」；
  - `義弟` 根据人物关系和视角译为 **「小叔子 / 妻弟」** 等自然称谓；
  - 其他亲属词同样先确认人物关系，再选择中文称谓；不得为了所谓「日式风格」「文库感」保留不自然的日语亲属词直译。
- **「義母 / 義父 / 義姉 / 義妹」**：必须严格结合人物关系网动态匹配：
  - 婚姻关系（姻亲）：男主对妻子母亲称 **「岳母 / 丈母娘」**，女主对丈夫母亲称 **「婆婆」**；兄之妻称 **「嫂子」**，妻之姐称 **「大姨子」**；
  - 再婚/收养家庭：称 **「继母 / 继父 / 继姐 / 继妹」** 或 **「养母」**；
  - **严禁**不顾剧情一律机械套用“义母/义姐”。

## 2.2 性爱技巧与动作描写原则（生动描摹，杜绝标签化）

- **「フェラチオ」**：重在唇舌动作描摹，自然译为 **「含弄 / 吞吐肉棒 / 吮吸 / 口爱 / 用唇舌侍奉」**，避免通篇死板使用“口交”；
- **「クンニ / クンニリングス」**：描摹感官动态，自然译为 **「埋头舔弄蜜穴 / 吮吸阴核 / 俯身舔舐密处」**；
- **「パイズリ」**：自然译为 **「用丰满的乳房夹弄肉棒 / 双峰套弄 / 乳房侍奉」**；
- **「手淫 / オナニー」**：依文风自然译为 **「自慰 / 手淫 / 自渎 / 抚慰下身」**；
- 动词与体位重在**情欲动作与感官体验的连贯描摹**，切忌将其机械标签化。

## 3. 负面约束与禁令（严防机翻感与现代网络化）

- **严禁现代网络烂梗与网文词汇**：严禁出现“给力、老铁、疯狂输出、开冲、震惊、直接破防”等现代网络词汇。
- **严禁生硬生理卫生教材/医学报告腔**：情欲与肉戏描写严禁使用冷冰冰的临床医学词汇。例如「中出し」严禁译为「体内射精」（应根据语境自然译为「射在里面 / 射进体内 / 射入深处 / 尽数射入」）；「陰茎」在情欲描写中应地道译为「肉棒」而非「生殖器/男性生殖器官」。
- **严禁生硬机翻欧化句式**：避免出现“做出了一个……的动作”、“导致了……的发生”等僵硬翻译腔。
- **严禁无端删减或凭空捏造**：忠实还原日文原文的所有情节、动作细节与心理描写，保持 1:1 段落编号映射。

## 4. 黄金文风示范（Few-Shot Examples）

### 【范例 1：对话与日常神态】
- **日文原文**：
  「西城先生、授業の様子はどうですか？もう慣れましたか？」
  「は、はい……なんとか……」
  「アメリカで生活していた人はやっぱり違いますね。みんなあなたの発音を絶賛していますよ。もちろん、素晴らしいのは発音だけではありませんが」
- **参考译文**：
  “西城老师，上课的情形怎么样？已经习惯了吧？”
  “是……总算……”
  “在美国生活过的人究竟不同。大家都说你的发音非常美。当然，美的不只是发音。”

### 【范例 2：肢体侵犯与心理抗拒】
- **日文原文**：
  男の手が太腿の付け根から上へと這い上がってきた。そのおぞましい感触に美穂子の体は激しく震え、必死にもがいて逃れようとした。しかし、すぐさま両足を掴まれて引き戻されてしまう。
- **参考译文**：
  男人的手从大腿根向上摸过来，那种恶心的感觉使美穗子的身体剧烈颤抖，只好挣扎着尽量逃避。可是立即被男人抓住双脚粗暴地拉了回去。

### 【范例 3：感官觉醒与快感沉沦】
- **日文原文**：
  敏感な陰核を巧妙な指先で弄ばれ、もう我慢できなくなっていた。体の奥深くから甘美な快感が湧き上がり、ソファを強く掴みながら腰をくねらせる。やがて、目の前が真っ白になるほどの眩暈を伴う絶頂へと駆け上がっていった。
- **参考译文**：
  敏感的阴核受到微妙手法的玩弄，快要忍不住了，从身体内部产生甜美的快感，使她双手抓住皮沙发，不停扭动软绵绵的身体。没有多久，就爬上头昏目眩的高潮。
